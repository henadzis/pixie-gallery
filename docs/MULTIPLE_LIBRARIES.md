# Руководство: Несколько библиотек фотографий (папок)

Pixie Gallery поддерживает работу с произвольным количеством независимых библиотек (папок с фотографиями). 

---

## 1. Как это работает

- **Основная библиотека (`default`)**: По умолчанию указывает на путь переменной окружения `PHOTOS_DIR` (в Docker это `/photos`).
- **Дополнительные библиотеки**: Хранятся в базе настроек `config_db.json`. Администратор может добавлять, редактировать и удалять библиотеки прямо через веб-интерфейс Настроек.
- **Переключатель в шапке**: Справа от кнопки «На главную» отображается минималистичная кнопка со стрелочкой вниз. Она открывает выпадающее меню со списком доступных библиотек. Если библиотека всего одна — кнопка скрывается.
- **Права доступа**: Каждому пользователю можно разрешить доступ ко всем библиотекам (`★ Все библиотеки`) либо только к выбранным. Пользователи видят в выпадающем списке только те библиотеки, к которым у них есть доступ.
- **Фоновая предгенерация**: При нажатии «Сгенерировать миниатюры» процесс поочередно обходит все настроенные библиотеки.

---

## 2. Настройка в Docker (`docker-compose.yml`)

Чтобы подключить к контейнеру несколько папок с разных дисков хост-системы:

1. Откройте `docker-compose.yml` и добавьте пути в секцию `volumes`:
```yaml
services:
  pixie:
    image: pixie-gallery:latest
    container_name: pixie-gallery
    environment:
      - PHOTOS_DIR=/photos
      - CACHE_DIR=/cache
      - ADMIN_PASS=your_password
    volumes:
      # Основной архив
      - /mnt/storage/photos:/photos:ro
      # Дополнительные папки на других дисках
      - /mnt/storage2/family_archive:/photos_family:ro
      - /mnt/external/work_shoots:/photos_work:ro
      # Папка кэша
      - ./cache:/cache
    ports:
      - "8085:8085"
    restart: unless-stopped
```

2. Перезапустите контейнер:
```bash
docker compose up -d
```

3. Войдите в веб-интерфейс под учетной записью администратора.
4. Откройте **Настройки** (иконка шестерёнки) $\rightarrow$ раздел **«Библиотеки фотографий (папки)»**.
5. Добавьте библиотеки:
   - **Название**: `Семейный архив`
   - **Путь в контейнере**: `/photos_family`
   - Нажмите «Добавить».
6. Галерея сразу проверит наличие папки на диске и отобразит зелёный бейдж `Доступна`.
7. В верхней панели появится кнопка переключения со стрелочкой вниз.

---

## 3. Настройка прав пользователей

В окне **Настройки** $\rightarrow$ **«Управление пользователями»**:
1. Создайте нового пользователя или нажмите **Редактировать** у существующего.
2. В блоке **«Доступные библиотеки»** отметьте нужные архивы.
3. Сохраните пользователя.
4. При входе под этим пользователем ему будут видны только назначенные библиотеки и альбомы.
