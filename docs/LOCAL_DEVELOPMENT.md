# Локальный запуск и разработка Pixie Gallery на macOS

Это руководство позволяет тестировать галерею прямо на вашем Mac без Docker и без необходимости коммитить и пушить в GitHub для сборки через GitHub Actions.

---

## 1. Быстрый старт

### Первоначальная настройка (один раз):
В корне проекта выполните:
```bash
./setup_local.sh
```
Этот скрипт:
- Создаст виртуальное окружение `.venv/`.
- Установит зависимости из `requirements.txt`.
- Создаст папки `test_photos/` (с демонстрационными альбомами) и `test_cache/`.

### Запуск галереи:
```bash
./run_local.sh
```

В консоли отобразится:
```text
==================================================
 Pixie Gallery запущена локально!
 URL:       http://localhost:8085
 Логин:     admin
 Пароль:    admin123
 Фото:      .../test_photos
 Кэш:       .../test_cache
 Режим:     Live-reload (правки применяются на лету)
==================================================
```

---

## 2. Рабочий процесс (Live-Reload)

1. Откройте в браузере: **`http://localhost:8085`**
2. Вход: логин `admin`, пароль `admin123`.
3. Редактируйте любые файлы проекта (`app/main.py`, `app/templates/index.html`).
4. При сохранении файла (`Cmd + S`) сервер автоматически перезапускается за **0.3 секунды**.
5. Нажмите `Cmd + R` в браузере — результат обновлен сразу!

---

## 3. Тестирование на реальных фотографиях

Если вы хотите запустить локальный сервер с вашими реальными фотографиями с Mac (например, из папки «Изображения»):
```bash
PHOTOS_DIR="/Users/henadzi/Pictures" ./run_local.sh
```
Или укажите внешний диск:
```bash
PHOTOS_DIR="/Volumes/ExternalDrive/Photos" ./run_local.sh
```
